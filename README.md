# Praveen Jamakhandi | AI-Generated Portfolio

A personal portfolio website built using HTML5 and CSS3 with AI assistance. This project showcases my introduction, technical skills, projects, resume, and contact information through a clean, dark-themed design.

## About the Project

This portfolio was created as part of my web development learning journey. It demonstrates my understanding of HTML structure, CSS styling, responsive layouts, and basic website design principles.

The website provides a central place to learn about me, explore my technical skills, view sample projects, and access my resume.

## Features

- **Home Section:** Personal introduction and portfolio headline.
- **About Me:** Background and web development interests.
- **Skills Section:** Overview of technical skills.
- **Projects Section:** Showcase of portfolio, landing page, and calculator projects.
- **Resume Section:** Resume download button.
- **Contact Section:** Email, phone number, and location.
- **Navigation Bar:** Links to different sections of the page.
- **Dark Theme:** Modern dark background with blue accent colors.
- **Responsive Layout:** CSS adjustments for smaller screens.
- **Google Fonts:** Poppins typography.
- **Reusable CSS Components:** Consistent styling for buttons, cards, sections, and layouts.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/praveenjamakhandi-pjj/ai-generated-portfolio.git
```

### 2. Open the Project Folder

```bash
cd ai-generated-portfolio
```

### 3. Run the Website

Open `index.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to preview the website.

No package installation or build process is required for the current HTML and CSS implementation.

## Customization

You can personalize this portfolio by:

- Updating the introduction and About Me content in `index.html`.
- Adding or modifying projects in the Projects section.
- Updating the styles, colors, spacing, and typography in `style.css`.
- Replacing `profile.jpg` and `profile2.jpg` with your preferred images.
- Replacing `resume.pdf` with your latest resume.
- Adding links to your GitHub, LinkedIn, and other professional profiles.
